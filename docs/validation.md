- 同一测量脚本各跑 3 次：旧版 3/3 次出现英文界面且整页重载，新版 0/3 次出现英文界面、0/3 次重载，首次绘制即为中文。
- 边界复核（[汉化边界](boundaries.md)）：主界面、商店、设置 35 个面板、更新日志、欢迎页与反馈页已无英文界面文案；仍为英文的只剩品牌与产品名（Raycast、Raycast AI、MCP）、第三方应用与命令名、主题与配色预设名、快捷键字形、路径与示例表达式、用户内容（笔记正文、账户名），以及 Pro 主题编辑器窗口。复核命令 `npm run audit:ui`。
- 修复两处安装缺陷：Store 载荷的 node.exe 带 EFS 加密属性，Copy-Item 会连带加密本地运行时并失败，改为按字节流复制；只复制了部分文件就中断的安装，卸载时不再因缺少 node.exe 停止清理。
- 本机完成卸载、安装、原版入口启动、退出、重启后自动重连与再次卸载的全流程。提权写入 WebView2 参数后，主界面、商店、自动深色模式和更新日志显示中文；启动、商店和主搜索页面无脚本异常。
- 退出经后台 `--quit` 请求生效，Raycast 正常退出，后台状态转为等待；原版入口重开后自动重新加载，状态回到 active 并继续替换资源。
- 卸载后安装目录、WebView2 参数、登录启动项、卸载项与快捷方式全部移除，插件文件无替换残留；原版以 `--hardened` 启动，命令行不含本机调试参数。
- 38 项自动化测试全部通过，按模块拆分为词典、注入与转换、插件、商店、安装、打包六组，可用 `npm run test:<模块>` 单独运行；`npm run test:fast` 只跑不依赖本机 Raycast 的四组（实测 1.7 秒），`npm test` 全量 6.4 秒。其中打包测试在真机上逐个校验 115 个文件的指纹，并把替换结果重新解析为模块。仅限当前用户环境，第二台电脑、ARM64 及组织管理策略限制的环境仍未验证；截图未更新。
- 启动、卸载与打包工具统一以 Windows PowerShell 5.1 为基线，不依赖需另行安装的 PowerShell 7，打包命令补上 `-ExecutionPolicy Bypass`。在 5.1.26100 上逐项复核：Appx 匹配、主程序与运行时指纹、115 个资源指纹、EFS 载荷按字节复制均通过，`npm run package` 在受限执行策略下也可完成。

- 发现 r3 从打包的 Codex 环境安装时，LocalAppData 被 Windows 重定向到该应用的私有 LocalCache。用户从资源管理器卸载时无法读取同一标记，因此误报“尚未安装”。此前同环境内卸载通过不足以证明跨环境卸载可靠。

- 在带中文和空格的解压目录启动安装，工作目录另设为系统临时目录，成功加载中文；随后从另一份解压目录执行卸载并恢复。
- 新增位置回归测试，覆盖新安装、普通旧安装、被重定向的旧安装，以及已有新版安装优先级。合计 17 项自动化测试通过。

## 实测边界

没有批量安装插件，没有登录外部服务，没有测试真实账号操作、付费功能、设备控制或所有命令。插件源码与 Store 已发布版本可能不同；运行时只翻译实际安装版本能安全识别的字面量。截图只显示本机已验收的界面，不代表所有页面均为中文。

**尚未在第二台真实电脑验证完整安装和界面。** 支持条件是当前用户已安装 Microsoft Store Raycast 2.12.1.0 x64 且指纹匹配。不能据此保证其他版本、ARM64、组织管理策略限制的环境或所有插件流程均可用。

更新保护：主程序版本或指纹变化时拒绝加载。插件更新时重新备份并分析；不支持的语法跳过并记录。汉化文件被用户手动修改时，卸载拒绝覆盖该文件并保留备份。
