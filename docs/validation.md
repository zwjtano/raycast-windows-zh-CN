- 安装不创建中文快捷方式，通过官方 AppsFolder 入口启动；主界面和商店列表截图确认中文显示。
- 后台首次启动加载 42 次中文资源，退出原版后保持等待；通过原版入口再次打开时重新加载。重复运行后台启动脚本不产生第二个工作进程。

- 真实卸载测试移除 Raycast 专属 WebView2 配置、登录启动项和后台，按插件备份恢复；原版重开成功初始化主窗口，没有汉化调试参数。随后重新安装成功。

- 重启前曾出现 WebView 初始化超时；已回滚，Windows 重启后恢复，复验成功，根因仍未确定，见[调查记录](original-entry-investigation.md)。安装后的登录自动启动项已检查，但尚未再次重启 Windows 验证自动登录加载；第二台电脑、多人同时登录尚未验收。

## 实测边界

没有批量安装插件，没有登录外部服务，没有测试真实账号操作、付费功能、设备控制或所有命令。插件源码与 Store 已发布版本可能不同；运行时只翻译实际安装版本能安全识别的字面量。截图只显示本机已验收的界面，不代表所有页面均为中文。

**尚未在第二台真实电脑验证完整安装和界面。** 支持条件是当前用户已安装 Microsoft Store Raycast 2.4.0.0 x64 且指纹匹配。不能据此保证其他版本、ARM64、组织管理策略限制的环境或所有插件流程均可用。

更新保护：主程序版本或指纹变化时拒绝加载。插件更新时重新备份并分析；不支持的语法跳过并记录。汉化文件被用户手动修改时，卸载拒绝覆盖该文件并保留备份。
